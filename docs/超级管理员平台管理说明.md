# 超级管理员平台管理

使用在线超级管理员账号登录，在左侧导航选择“平台管理”。其他角色不显示该入口，服务端也会拒绝其访问管理接口。

## 全平台账号管理

- 查看全平台账号、角色、启用状态与创建时间。
- 新建超级管理员、安全管理员、项目经理、普通人员账号。
- 调整其他账号角色；变更后原登录会话失效，需要重新登录。
- 停用或启用账号；停用会立即撤销原有会话。
- 重置密码（8～128 位）；旧密码和旧会话立即失效。
- 当前超级管理员不能停用或降级自己。

密码不会出现在账号列表中。重置密码使用密码输入框，保存成功后清空输入内容。

## 智能体 API 全局配置

在第二个页签填写 API 密钥、接口地址、模型名称并保存。接口需要兼容 OpenAI Chat Completions；情景助手还要求服务支持 JSON object 响应格式。

接口地址填写基础路径，例如 `https://api.deepseek.com` 或服务商提供的 `https://服务地址/v1`，不要追加 `/chat/completions`，不要把密钥放入地址。

保存后，所有已登录用户的 AI 安全助手和情景助手，都会在后续请求中统一读取该配置，无需逐个账号配置或重启服务。

- 密钥保存在服务端数据库；管理页面仅返回掩码，普通用户无法读取配置。
- API 密钥输入框留空表示保留现有密钥。
- “清除全局密钥”会停用全平台在线 AI；即使后端仍有旧环境密钥，也不会回退使用。
- 尚未保存过全局配置时，兼容读取原后端环境变量。
- 保存配置不代表服务商连通性已验证，真实可用性以 AI 请求结果为准。

配置表 `platform_settings` 会在后端启动时自动创建。部署时需同时更新前后端并重启后端服务，以加载新增管理路由。
