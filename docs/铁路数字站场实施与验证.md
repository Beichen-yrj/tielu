## 改动内容

原数字工厂已替换为六地区铁路危货站场。主平台入口改为“铁路数字站场 / 演示”，原 `digital-factory-3d.html` 文件名保留兼容。

每地区均可选择进场核验、罐车装卸、包装危货站台、到发调车、暂存交接、应急保障六个作业点。模型包括轨道、道岔示意、机车、罐车、棚车、站台、装卸栈台、值守与应急设施。

风险分级与隐患分别由独立教学记录提供，参数和车辆动画不修改等级或治理状态。点击风险分级、隐患条目、分区或三维作业区可查看对应详情。

温度、风速、风向和周边敏感目标作为演练假设按地区保存在浏览器会话。站场简报可预览并下载 Markdown。主平台通过 Portal 挂载全屏场景，避免原侧栏覆盖；关闭后销毁 iframe、恢复页面滚动和原搜索状态。

### 动态效果增补

- 一台机车牵引四节棚车/罐车沿独立通行股道经过，车轮随行程旋转。列车在站场边缘裁切、场外复位；装卸股道上的车辆保持停放。
- 四名穿反光服、戴安全帽的人员分别沿栈台、包装货运站台和地面人行通道巡检，具有迈步摆臂、驻点查看平板、转身返回动作；路线不穿越股道。
- 新增“动态暂停 / 继续”，统一控制列车、人员、演练时钟和空闲视角漂移；顶部 1× / 2× / 4× 控制演示速度。六地区切换、后台暂停和冻结截图兼容。
- 动画仅作视觉演示，不生成巡检台账、隐患或整改记录，不修改风险等级与业务统计。

## 2026-11-17 模型招牌文字修复

原招牌统一使用 512 × 96 贴图，而模型牌面宽高比各不相同，文字因此被拉伸；叠加画面边缘景深模糊后，小字进一步失真。现按实际牌面宽高比生成最高 4096 像素宽的贴图，使用适配字号、居中排版和各向异性过滤；背面独立朝向，避免文字镜像。移除后处理中的边缘景深模糊，保留色调与光晕。

已通过六地区场景规则测试、React 静态检查及生产构建。本地浏览器检查了应急保障区斜视近景、正面近景和站场总览；近景招牌字形比例正常，error 日志为空。截图：[模型文字修复](../qa-df/results/railway-signage-fixed.jpg)。远景仍受屏幕像素和透视限制，可通过缩放或作业点标签读取名称。

## 交付边界

- 六地区是程序化示范模板，未绑定真实铁路局和实际站场，不证明危货办理许可或真实测绘布局。
- 未接入真实业务记录、监测数据、现场照片上传或经实测标定的影响范围。
- 正式风险评估、整改、复核和销号仍在原系统，本页不创建正式隐患，不覆盖风险等级，不回写任务。
- 未实现爆炸超压、热辐射、人员伤害或设备损毁计算。Markdown 简报不替代 PDF 中要求的专项计算报告。
- 离线 HTML 已生成并核对一致性；本轮浏览器检查使用 HTTP 页面，未把此结果表述为 `file://` 实测或断网测试。
- 本轮没有修改后端、数据库和权限逻辑，没有部署、提交评审或发布。

若继续接入真实局站，应先补齐业务确认的站场档案、办理货类、测绘/图片、参数来源和原评估记录的关联契约；专项计算须另行落实公式、适用范围与校核算例。
