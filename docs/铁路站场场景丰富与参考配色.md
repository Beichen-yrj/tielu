# 铁路站场场景丰富与参考配色

日期：2026-11-17。依据用户提供的大屏参考图，调整铁路数字站场及情景工作区；保留危险源快照、AI 建议、演练控制及原整改流程。

## 视觉与数据面板

- 深海军蓝底色、亮蓝渐变标题栏、居中标题、青蓝边框与半透明数据面板；字体继续优先微软雅黑。
- 分级计数改为环形展示，环的占比来自当前风险计数；治理状态新增横向条形分布，使用当前记录的整改、复核、闭环数。没有虚构历史趋势或监测曲线。
- 平台快照与离线教学数据继续区分，平台空记录显示零条，逾期/闭环率按原有未知语义保留。
- 调整总览为更高的俯视机位，保留环绕、缩放、巡游、图层与地区切换；保留移动端折叠面板和内部滚动。

## 场景内容

新增 `daima/src-df/57-yard-context.js`，包括：

1. 四栋通用后勤建筑：普通物资仓库、货运综合楼、检修器材库、消防泵房；补充屋面筋条、通风装置、窗带、卷帘门、装卸口和防撞构件。
2. 后勤道路、入口连接、斑马线、方向箭头、停车位和边界标线；与原作业道路连接。
3. 三辆停放货车、四辆小车和一台叉车；叉车含门架、护顶架和货叉。它们是场景设施，不构成新增运输任务。
4. 消防水设施、管线、物资货架、空装卸框架、绿化隔离带、树木和双臂路灯。
5. 轨旁电缆沟、设备箱、照明杆和批量道砟细节；有空闲股道的模板增加三节普通货物/空架车辆，三股道的西南模板不增加该组车辆。

新增建筑、停放车辆安排在原装卸区以南；静态新增列车不占动态通行线、罐车装卸线或包装货物线。修改了检修库尺寸及管线绕行，避免与消防水设施相交。这些是通用场景的几何避让，不代表真实站场安全距离校核或设计合规。

六地区原地形、临港水面、山地、风沙及寒地元素保留。原列车与四人巡检继续使用原运动控制，事故演示仍由危险源与物料条件驱动；新增建筑不改变业务统计，不新增危险货物库存。
