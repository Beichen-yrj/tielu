## 1. 从当前实现提炼的提示词

制作一个可在本地浏览器和离线单文件中运行的三维数字工厂视觉演示，主题为新能源汽车工厂。以可读的工业空间、完整工艺链路、细致设备和连贯运行为核心，让用户能够总览、巡检、聚焦并录制场景。

### 场景

- 剖切式厂房，当前示意范围约 156 × 80 m，让内部设备、物流和工艺连续性清晰可见。
- 六个生产分区：原材料立库、冲压线、焊装车间、涂装车间、总装线、检测发运。
- 包含多层货架和堆垛机、伺服压机、焊装机器人、喷涂与烘干、双线总装、检测光廊、物流月台和室外能源站。
- AGV、卡车、车身输送、作业人员和设备动作让空间具有连续运行感。
- 设备、地面、钢结构、玻璃和车身材质有区别；灯光、阴影和金属反射服务于空间辨识。

### 界面

- 全屏三维画布作为视觉主体，周围叠加轻量 HUD。
- 顶部显示场景标题、时钟、演示速率和返回入口。
- 左侧展示六个生产分区，中央显示当前视角，右侧展示生产数据，底部放置场景工具栏。
- 数据包括 OEE、当班产量、在制车辆、AGV 在线与电量、能耗、运行事件；当前均为本地演示数据。
- 分区悬浮标签、设备信标和巡检卡片保持关联，选择设备后可聚焦。

### 交互与动画

- 鼠标拖动环绕，滚轮缩放；触屏支持单指环绕和双指缩放。
- 点击分区、设备或导航，显示详情并飞行到对应视角。
- 支持总览、自动巡游、数据层、标签、复位、全屏和帮助。
- 支持 1× / 2× / 4× 演示速率。
- 支持纯净录屏、电影遮幅、隐藏界面和 Esc 退出。
- 当前自动巡游为 88.5 秒、九章循环，覆盖总览、六个工艺分区、升空和回到总览。
- 提供冻结画面、低画质和指定机位参数，便于截图与验证；后台页面暂停动画。

### 工程

- 采用现有 three.js r160、本地脚本与程序化几何/纹理；保留 MIT 许可。
- 源码拆分维护，由 `daima/build-df.js` 内联为单文件 HTML，避免直接修改生成文件。
- 构建输出为 `daima/public/digital-factory-3d.html` 和项目最外层 `digital-factory-3d.html`。
- 在现有 React 平台通过 iframe 打开，退出时保留原业务页面与搜索状态，关闭后结束独立动画。
- 使用实例化、几何和材质复用、分档画质与像素比控制渲染成本。
- 校验离线打开、分区导航、聚焦、巡游、退出、移动布局和浏览器错误。

## 2. 铁路版应保留与替换的内容

| 工厂演示内容 | 铁路版对应内容 |
| --- | --- |
| 工艺链与生产分区 | 进场检查、到发/调车、罐车装卸栈台、危货装卸站台、暂存交接、应急保障 |
| 厂房、压机、机器人、整车生产线 | 铁轨、道岔、货运站台、栈桥、罐车、货车、集装箱、调度与消防设施 |
| 产量、OEE、WIP、AGV、电量和能耗 | 评估风险分级、当前未闭环隐患、逾期隐患、闭环率和巡检记录 |
| 设备运行/暂停 | 作业点状态、监测状态、风险依据和已确认隐患；设备离线不自动判定隐患 |
| 一座固定总装车间 | 不同地区的货运站场与站台模板，支持局站和站内作业点选择 |
| 工厂生产巡游 | 铁路危货作业与风险管控巡游 |
| 通用设备卡片 | 风险详情、隐患证据与治理阶段、场站环境参数 |
| 工厂本地运行数据 | 显式标记的铁路示范数据；接入业务数据时使用原接口和权限 |

保留可复用的相机控制、拾取、标签、巡游、录屏、离线构建和平台返回能力。工厂业务语义应整体替换，不能只更换标题、继续展示冲压/焊装和产量。
