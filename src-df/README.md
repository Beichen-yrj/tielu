# 铁路风险与隐患数字站场

2026-11-15：原数字工厂已改为铁路危货站场，沿用 three.js r160、离线单文件构建和 React iframe 接入。平台顶部入口为“铁路数字站场 / 演示”。

## 已实现

2026-11-17：平台入口提供“铁路情景工作区”，支持评估快照、模板映射、照片标注、五类条件化情景、AI 建议、时间轴和 Word/Excel 导出；“浏览六地区站场”按平台授权快照展示。配置按账号保存在浏览器会话，可导入导出 JSON。在线建议复用 DeepSeek 后端，仍需密钥及在线登录；未接入 AI 图片建模或定量后果计算。详见 [最新实施与验证](../docs/铁路危险源联动与AI场景优化.md)。

- 东北、华北、华东、华南、西南、西北六种示范站场。切换时重新载入当前 iframe，统一重建布局、股道、作业点、风险与隐患记录，并释放上一场景的 WebGL 上下文。
- 铁轨、轨枕、道岔示意、信号、机车、罐车、棚车、罐车栈台、包装危货站台、进场核验、暂存交接、消防与应急保障设施。
- 地区差异包括寒地积雪、城市边缘、水网临港、湿热植被、山地谷地、防风沙设施；股道数、站台位置和棚体配置不同。棚体采用剖切方式展示，便于查看车辆。
- 六个可选作业点；点击场景、分区索引、风险分级或隐患项查看关联信息。风险与隐患来自分开的固定教学样例，不自动随机制造风险或隐患。
- 未闭环、逾期、待复核、闭环率统计，与对应地区样例记录一致。已闭环数量是显式教学汇总，不是正式业务台账。
- 环境演练参数：温度、风速、风向、敏感目标描述。数值范围和单位校验；空值保持未知。按地区保存在当前浏览器会话，受限浏览器下退化为本页内存并给出提示。
- 站场综合简报预览和 Markdown 下载；内容包含当前地区、参数、风险与隐患样例、数据边界。
- 动态列车：机车牵引四节货车沿第一条通行股道经过，车轮随行程旋转；通过站场边界裁切，在场外完成循环复位，不占用装卸股道。
- 四名安全人员沿装卸栈台、包装危货站台及地面人行通道往返巡检，包含摆臂迈步、驻点查看、转身返回。巡检演示不生成正式检查记录。
- “动态暂停 / 继续”同时控制列车、巡检人员、演练时钟和空闲视角漂移；1× / 2× / 4× 统一控制演示速度。后台暂停、冻结截图与地区切换重建均兼容。
- 保留环绕、缩放、风险层、标签、复位、九章巡游、纯净录屏、全屏、Esc 退出、后台暂停及低画质。移动布局保留地区/作业点选择、详情、参数和简报入口。

## 打开与构建

- 平台：`http://127.0.0.1:5173/#/`，进入管理平台后点击“铁路数字站场”。
- 独立预览：`http://127.0.0.1:5173/digital-factory-3d.html`。
- 双击项目最外层 `digital-factory-3d.html` 可离线打开。该文件名为兼容原链接保留，页面内容已替换为铁路。
- `node build-df.js` 同步生成最外层单文件和 `public/digital-factory-3d.html`；`npm run build` 还会构建 React 平台。
- three.js 及 MIT 许可继续内联，运行不依赖在线模型、地图、字体或图片。

## URL 与操作

- `?region=NE|NC|EC|SC|SW|NW`：地区。未知地区回到东北示范场景。
- `?view=Z01` 到 `Z06`：指定作业点；`?tour=1` 巡游，`?film=1` 纯净录屏。
- `?lq=1`：低画质；`?still=1`：初始冻结列车、巡检人员与自动视角漂移，可点击“动态继续”恢复角色动画。
- `?tourat=25`：定格巡游；`?tour=1&tourfast=1`：加速巡游。
- 原有 `raw`、`pr`、机位参数及图层预设继续可用。
- `0` 总览，`1–6` 作业点，`Space` 巡游，`D` 风险层，`L` 标签，`H` 隐藏界面，`B` 遮幅，`F` 全屏，`Esc` 退出纯净模式/关闭详情。

## 源码

- `theme.css` / `dashboard.css`：蓝黑科技风、微软雅黑、固定标题与独立滚动数据侧栏；索引置于底部，900px 以下索引横向滚动、数据面板按需展开。构建时内联到单文件。

- `05-regions.js`：地区模板、独立风险/隐患教学记录和统计。
- `10-util.js` / `20-studio.js`：几何、材质、渲染和灯光。使用原生画布抗锯齿、单次 ACES/sRGB 输出、像素预算和稳定的缓冲尺寸，避免叠加半浮点 MSAA 离屏后处理。
- `30-building.js`：铁路土建、轨道和地区地形；`40-process.js`：站台、栈台与站房；`45-logistics.js`：铁路车辆、巡检人员与运动；`50-assembly.js`：环境构件。原模块名为兼容构建保留。
- `55-rail-details.js`：转向架、阀组、装卸软管、接地/防溜/探测/收集等通用设施。
- `57-yard-context.js`：后勤建筑、消防水设施、货车/小车/叉车、停车与道路、绿化照明、道砟及空闲股道普通车辆；通用几何，非现场设计。参考配色和验证见 [场景丰富与参考配色](../docs/铁路站场场景丰富与参考配色.md)。
- `58-dashboard-model.js`：原等级、治理阶段、闭环率、有效耗时样本和原措施去重汇总；`60-data.js`：拾取、标签、详情、环图/梯形图数据面板，以及平台授权快照模式；`70-post.js`：后处理、机位与巡游；`80-ui.js`：参数与简报；`85-scenario.js`：物料/风况/点火/积聚条件化的五类定性演示和父窗口控制协议；`90-boot.js`：事件和动画启动。

## 验证

- `node qa-df/label-stability-contract.cjs`：标注贴近面板时反复显隐的回归、隐藏后尺寸保留、边缘迟滞、标签开关和窄屏/换行尺寸。
- `node qa-df/render-stability-contract.cjs`：单次场景输出、缓冲预算、重复尺寸不重建、上下文丢失时暂停渲染及恢复环境光照。浏览器真实中断恢复验证页为 `qa-df/render-recovery.html`，采样分析脚本为 `qa-df/analyze-flicker-frames.py`；本轮结果见 [闪屏修复与验证](../docs/铁路站场闪屏修复与验证.md)。
- `node qa-df/dashboard-contract.cjs`：原风险等级、六阶段互斥统计、闭环分母、空值/零值、耗时样本覆盖、原措施去重和闭环日志选择。布局与统计口径见 [底部索引与侧栏可视化](../docs/铁路站场底部索引与侧栏可视化.md)。
- `node qa-df/railway-contract.cjs`：六地区实际几何、变换数值、站台净空、列车通行/轮转/场外复位、巡检路线/驻点/冻结姿态、地区记录隔离、统计一致性、两份离线产物一致性及脚本语法。
- `node qa-df/scenario-contract.cjs`：配置校验、来源不可变、Office 包、六地区 × 三对象 × 五情景、风向/静风、物料/点火条件、确定性定位、平台空数据及统计、阶段与播放控制和消息边界。
- `npm run lint -- src`：React 源码静态检查。场景分片经构建拼接为同一脚本；单独 lint 每个分片会产生跨文件变量未使用提示。
- `npm run build`：离线场景、TypeScript 与 Vite 生产构建。
- 本轮浏览器验证与限制见项目根目录 `docs/铁路数字站场实施与验证.md`。
- `qa-df/verify.cjs` 与 `integration.cjs` 保留为可选 Playwright 回归入口，已更新铁路分区断言；本轮未执行，旧 `results/report.json` / `integration.json` 不作为新版本证据。

## 边界

平台工作区读取已授权评估快照，可上传照片标注、调用情景建议并返回原记录；独立离线文件使用教学数据。没有实时监测或后台推送，六地区布局仍是通用模板，不代表真实测绘或场站危货办理许可。在线 AI 配置和最新证据见 [铁路危险源联动与AI场景优化](../docs/铁路危险源联动与AI场景优化.md)。

正式风险评估、隐患整改、复核和销号仍在原系统。本页不生成正式隐患、不改变原评估等级，不计算爆炸超压、热辐射或伤害半径，不回写任务。下载的是 Markdown 示范简报，不是 PDF 专项计算报告。

改造提示词：项目根目录 `docs/PROMPT-铁路风险与隐患.md`；原工厂提炼归档：`docs/数字工厂提示词提炼.md`。

Git 仓库内实施文档位于 docs/；测试截图、采样和导出文件保留在本地 qa-df/results/，不随源码上传。可选浏览器回归需自行安装 Playwright，或通过 PLAYWRIGHT_MODULE / PLAYWRIGHT_EXECUTABLE 指定运行环境。
